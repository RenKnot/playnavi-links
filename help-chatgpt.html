ChatGPT 連携の設定方法

ChatGPT に PlayNavi を追加すると、ChatGPT との会話で、あなたの好みやプレイ記録をもとに次に遊ぶゲームを相談したり、遊んだゲームのことを話すだけでモーメントやログの下書きを作ったりできます。

ChatGPT 連携は現在ベータ版です。PlayNavi アプリのお知らせからお申し込みいただき、ご利用開始のお知らせが届いた方がご利用いただけます。お知らせが届く前に設定すると、手順 5 で「承認された方だけ」と表示されて先に進めません。

設定の手順（パソコンで・5 分ほど）

パソコンのブラウザ、ChatGPT のアカウント（無料プランでもご利用いただけます）、PlayNavi のアカウント（ご利用開始のお知らせが届いたもの）をご用意ください。設定は最初の一度だけです。

  1. パソコンのブラウザで chatgpt.com を開き、ログインします スマートフォンの ChatGPT アプリでは設定できません。
  2. 左のメニューの「プラグイン」を開き、右上の「追加」→「カスタム MCP サーバーを追加」を選ぶ 「追加」を押すと「プラグインを作成」「プラグインアーカイブをアップロード」「カスタム MCP サーバーを追加」の 3 つが表示されます。「カスタム MCP サーバーを追加」を選んでください。
    • ChatGPT の更新により、画面の表示名が変わることがあります。
  3. 表示された画面で、次のように入力します
    名前PlayNavi
    接続タイプ「サーバー URL」のまま、下の欄に https://ai.playnavi.app/mcp を入力
    認証「OAuth」を選択
    アイコン・説明入力しなくてかまいません
    OAuth の詳細設定開かずに、そのままにしてください（クライアント ID などの入力は不要です）
  4. 「理解したうえで続けます」にチェックを付けて「作成」を押します 「カスタム MCP サーバーの利用にはリスクが伴います」という注意が表示されます。PlayNavi が ChatGPT の公式プラグインとして公開されるまでは、必ず表示される注意です。入力した URL が https://ai.playnavi.app/mcp であれば、PlayNavi の公式の接続先です。
  5. PlayNavi にログインし、「ChatGPT と PlayNavi を連携しますか？」の画面で「連携する」を押します PlayNavi のログイン画面が表示されます。
    • PlayNavi アプリで使っているのと同じ方法（Apple または Google）でログインしてください。違う方法でログインすると、別のアカウントとして扱われ「承認された方だけ」と表示されます。
    • 「連携する PlayNavi アカウント」がご自身のアカウントであることを確かめてから押してください。ChatGPT の画面に戻れば設定は完了です。
  6. 話しかけてみましょう 新しいチャットで「PlayNavi で私のプロフィールを見せて」と話しかけてみてください。
    • ChatGPT から PlayNavi の利用の許可を求められたら、許可してください。
    許可しても、PlayNavi の記録が勝手に変わることはありません。記録の追加・変更・削除は、すべて PlayNavi の確認箱に下書きとして届き、あなたが確定するまで記録は変わりません。確認なしにその場で反映されるのは、チェックイン・チェックアウト（とチェックインの取り消し）、希望価格、AI が作った下書きの取り下げだけです。

ベータ版に関するご意見

よりよい機能にしていくため、使ってみたご意見・ご感想を、#PlayNaviChatGPT を付けて SNS に投稿していただけるとうれしいです。

SNS への投稿が難しい方は、PlayNavi アプリのメニューの「問い合わせ・リクエスト」から、種類「機能追加リクエスト」を選んでお送りください。どちらも任意です。

うまくいかないとき

  • 「承認された方だけ」と表示される：ご利用開始のお知らせが届いたアカウントと、ログインしたアカウントが違う可能性があります。PlayNavi アプリと同じ方法（Apple または Google）でログインし直してください。お知らせがまだ届いていない場合は、届くまでお待ちください。
  • 自分の記録が表示されない：別のアカウントと連携している可能性があります。PlayNavi アプリの「設定 → AIとプレイログの設定 → 連携中の AI と渡す内容」に ChatGPT が表示されているかご確認ください。表示されていない場合は、ChatGPT の「プラグイン」から PlayNavi を削除し、手順 2 から設定し直してください。
  • ChatGPT が PlayNavi を使わずに答える：「PlayNavi で」と付けて話しかけてみてください。

ご利用にあたって

  • PlayNavi が ChatGPT の公式プラグインとして公開された後は、この手順で追加した PlayNavi を削除し、公式プラグインから追加し直していただく必要があります（その際は PlayNavi アプリでお知らせします）。
  • ベータ版は、予告なく提供を終了する場合があります。終了すると ChatGPT から PlayNavi は使えなくなりますが、PlayNavi の記録はそのまま残ります。
  • ChatGPT から PlayNavi へ写真や動画は送れません。下書きになるのは文章だけなので、写真や動画は PlayNavi アプリか Web の確認箱で下書きに追加してください。
  • ChatGPT に渡す内容の変更や連携の解除は、PlayNavi アプリの「設定 → AIとプレイログの設定 → 連携中の AI と渡す内容」か、ChatGPT の「プラグイン」からできます。

取り扱う情報については、プライバシーポリシー の「6-2. AI サービスとの連携」をご覧ください。

Connect ChatGPT to PlayNavi (English, beta)

ChatGPT integration is in beta: only PlayNavi accounts that applied in the app and received the start-of-use notice can connect; others see "only approved users" on the PlayNavi page. On a computer, open chatgpt.com, open Plugins in the left menu, then Add → Add custom MCP server (カスタム MCP サーバーを追加). Enter the name PlayNavi, keep the connection type "Server URL" with https://ai.playnavi.app/mcp, choose OAuth and leave the OAuth advanced settings as they are. Tick "I understand and want to continue" for ChatGPT's custom MCP server notice and press Create. Sign in to PlayNavi with the same method you use in the app (Apple or Google), check the account shown and press 連携する. Every change the AI asks for (add, change or delete a record) waits as a draft in the PlayNavi inbox until you confirm it. If you can, please share your feedback on social media with #PlayNaviChatGPT, or send it from 問い合わせ・リクエスト in the PlayNavi app menu (both optional). Once PlayNavi is available as an official ChatGPT plugin, remove the one you added here and add the official plugin instead.
